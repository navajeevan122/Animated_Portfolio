## 🚀 Getting Started

### 1) Clone

```bash
git clone https://github.com/navajeevan122/Animated_Portfolio.git
cd Animated_Portfolio
```

### 2) Install Dependencies

```bash
npm install
```

### 3) Run Locally

```bash
npm run dev
```

### 4) Production Build

```bash
npm run build
```
